# Быстрый старт - Тестирование AI модели

## Что изменилось

Теперь система тестирования работает **только с картами Таро**, без анализа изображений:
- ✅ Автоматическая генерация случайных карт для каждого теста
- ✅ Оценка качества чтения карт разными оракулами
- ✅ Сравнение производительности между типами оракулов
- ❌ Анализ изображений временно отключен

## Быстрые команды

### 1. Запустить простой тест
```bash
npm run test:ai:example
```

### 2. Запустить полный тест со всеми оракулами
```bash
npm run test:ai run --evaluate --export results.html
```

### 3. Запустить тест только с одним оракулом
```bash
npm run test:ai run --oracles cosmic-oracle --count 5 --evaluate
```

### 4. Посмотреть производительность
```bash
npm run test:ai:performance
```

### 5. Сравнить оракулов
```bash
npm run test:ai:compare
```

## Что тестируется

Каждый тест:
1. **Генерирует 3-5 случайных карт Таро**
2. **Создает чтение** с помощью выбранного оракула
3. **Оценивает качество** по 5 критериям:
   - Релевантность выбранных карт
   - Связность чтения
   - Соответствие стилю оракула
   - Качество пользовательского опыта
   - Соответствие вопросу

## Типы оракулов

- `cosmic-oracle` - Мистический и интуитивный
- `astral-sorcerer` - Мудрый и ученый
- `alien-seer` - Инопланетная перспектива
- `mechanical-prophet` - Аналитический и точный

## Результаты

После тестирования вы получите:
- **JSON отчет** с детальными данными
- **HTML дашборд** с визуализацией
- **CSV файл** для анализа в Excel
- **Метрики производительности** (время ответа, использование токенов)

## Пример программного использования

```typescript
import { runQuickTest, basicTestDataset } from './src/testing';

const result = await runQuickTest(
  basicTestDataset.testCases.slice(0, 3),
  {
    oracles: ['cosmic-oracle'],
    locale: 'ru',
    name: 'Мой тест'
  }
);

console.log(`Успешных тестов: ${result.summary.successfulTests}`);
```
