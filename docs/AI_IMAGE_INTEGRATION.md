## Переменные окружения

Для работы AI необходимо добавить в файл `.env` (или переменные окружения на сервере):

```bash
OPENAI_API_KEY=sk-...ваш-ключ-от-openai...
```

### Как получить API ключ OpenAI:

1. Зайдите на [OpenAI Platform](https://platform.openai.com/)
2. Войдите в свой аккаунт или создайте новый
3. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)
4. Нажмите "Create new secret key"
5. Скопируйте ключ (он начинается с `sk-`)
6. Добавьте его в `.env` файл как `OPENAI_API_KEY=sk-...`

⚠️ **Важно**: Никогда не коммитьте `.env` файл в Git! Ключ должен быть только в переменных окружения.

### Для локальной разработки:

Создайте файл `.env.local` в корне проекта `oracle/`:

```bash
OPENAI_API_KEY=sk-ваш-ключ-здесь
```

### Для продакшена (Vercel/другие платформы):

Добавьте переменную `OPENAI_API_KEY` в настройках проекта на вашей платформе хостинга.

## Важные моменты

1. **Формат изображений**: Убедиться, что base64 строки правильно форматируются для OpenAI API
2. **Безопасность**: Whitelist проверка должна быть на сервере (в server action)
3. **Производительность**: OpenAI API может быть медленным, убедиться в правильной обработке loading states
4. **Стоимость**: OpenAI Vision API стоит дороже, поэтому важно ограничить доступ
5. **API ключ**: Без `OPENAI_API_KEY` реальный AI не будет работать, будет использоваться только stub
