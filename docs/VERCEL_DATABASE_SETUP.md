# Подключение базы данных в Vercel

## Вариант 1: Vercel Postgres (Рекомендуется)

### Шаг 1: Создайте проект в Vercel

1. Перейдите на [Vercel](https://vercel.com/)
2. Войдите в аккаунт (или создайте новый)
3. Нажмите **"Add New..."** → **"Project"**
4. Импортируйте ваш репозиторий с GitHub/GitLab/Bitbucket
   - Если репозиторий еще не на GitHub, сначала загрузите код туда

### Шаг 2: Создайте базу данных Vercel Postgres

1. В вашем проекте на Vercel перейдите в раздел **"Storage"** (Хранилище)
2. Нажмите **"Create Database"** (Создать базу данных)
3. Выберите **"Postgres"**
4. Выберите план:
   - **Hobby** (бесплатно) - для разработки и небольших проектов
   - **Pro** - для продакшена с большей нагрузкой
5. Выберите регион (ближайший к вашим пользователям)
6. Введите название базы данных (например, "oracle-db")
7. Нажмите **"Create"** (Создать)

### Шаг 3: Получите строку подключения

После создания базы данных:

1. В разделе **"Storage"** нажмите на вашу базу данных
2. Перейдите на вкладку **"Settings"** (Настройки)
3. Найдите раздел **"Connection String"** (Строка подключения)
4. Скопируйте строку подключения (она выглядит примерно так):
   ```
   postgres://default:password@host.vercel-storage.com:5432/verceldb
   ```

### Шаг 4: Добавьте переменную окружения в Vercel

1. В вашем проекте на Vercel перейдите в **"Settings"** → **"Environment Variables"**
2. Нажмите **"Add New"**
3. Добавьте переменную:
   - **Name:** `DATABASE_URL`
   - **Value:** вставьте скопированную строку подключения
4. Выберите окружения, где она будет доступна:
   - ✅ Production
   - ✅ Preview
   - ✅ Development
5. Нажмите **"Save"**

### Шаг 5: Примените схему базы данных

После добавления переменной окружения:

1. **Локально** (если хотите протестировать):

   ```bash
   # Добавьте DATABASE_URL в ваш локальный .env файл
   # Затем выполните:
   pnpm db:push
   ```

2. **Или через Vercel CLI**:

   ```bash
   # Установите Vercel CLI (если еще не установлен)
   npm i -g vercel

   # Войдите в Vercel
   vercel login

   # Свяжите проект с Vercel
   vercel link

   # Примените схему к базе данных
   vercel env pull .env.local  # Скачать переменные окружения
   pnpm db:push
   ```

3. **Или через Vercel Dashboard**:
   - После деплоя проекта, Vercel автоматически применит миграции
   - Или используйте Prisma Studio для ручного управления:
     ```bash
     pnpm db:studio
     ```

## Вариант 2: Supabase (Альтернатива)

Если хотите использовать Supabase вместо Vercel Postgres:

### Шаг 1: Создайте проект в Supabase

1. Перейдите на [Supabase](https://supabase.com/)
2. Войдите в аккаунт (или создайте новый)
3. Нажмите **"New Project"**
4. Заполните данные:
   - **Name:** название проекта
   - **Database Password:** придумайте пароль (сохраните его!)
   - **Region:** выберите регион
5. Нажмите **"Create new project"**

### Шаг 2: Получите строку подключения

1. В вашем проекте перейдите в **"Settings"** → **"Database"**
2. Найдите раздел **"Connection string"**
3. Выберите вкладку **"URI"**
4. Скопируйте строку подключения (она будет содержать ваш пароль)

### Шаг 3: Добавьте в Vercel

1. В Vercel: **Settings** → **Environment Variables**
2. Добавьте `DATABASE_URL` со значением из Supabase
3. Сохраните

## Проверка подключения

После настройки базы данных:

1. **Локально:**

   ```bash
   # Проверьте подключение
   pnpm db:studio
   # Откроется Prisma Studio в браузере
   ```

2. **В Vercel:**
   - После деплоя проверьте логи на наличие ошибок подключения
   - Приложение должно работать без ошибок

## Важные моменты

### Безопасность

⚠️ **Никогда не коммитьте строку подключения в Git!**

- Используйте только переменные окружения
- `.env` файл должен быть в `.gitignore`

### Миграции

После изменения схемы Prisma:

```bash
# 1. Генерируйте клиент
pnpm db:generate

# 2. Применяйте изменения к БД
pnpm db:push

# Или создайте миграцию (для продакшена)
pnpm prisma migrate dev --name your-migration-name
```

### Локальная разработка

Для локальной разработки:

1. Скопируйте `DATABASE_URL` из Vercel
2. Добавьте в локальный `.env` файл:
   ```env
   DATABASE_URL="postgres://..."
   ```
3. Примените схему:
   ```bash
   pnpm db:push
   ```

## Troubleshooting

### Ошибка "Connection refused"

- Проверьте, что `DATABASE_URL` правильно скопирован
- Убедитесь, что база данных создана и активна
- Проверьте, что IP не заблокирован (для некоторых провайдеров)

### Ошибка "Database does not exist"

- Убедитесь, что база данных создана
- Проверьте имя базы данных в строке подключения

### Ошибка "Password authentication failed"

- Проверьте пароль в строке подключения
- Для Supabase: убедитесь, что используете правильный пароль проекта
